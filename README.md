### The problem I'm working on

Detection is largely solved. Great Expectations, Soda, Elementary and dbt tests will all tell you *that* something broke.

Almost nothing tells you **why**.

When a pipeline fails at 3am, the expensive part isn't noticing — it's working out what caused it. That's where I'm focused: taking a failed run's error log, recent schema history and table lineage, and producing a ranked set of root-cause hypotheses with the evidence for each.
